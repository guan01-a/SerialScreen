# SerialScreen
串口屏测试专用代码

## 串口屏预备功能 ##
1.BOX           画矩形指令（预留接口，待完善）          
2.JUMP          跳转页面指令（已完善，目前预存3页）
3.NUM           设置数字指令（预留接口，待完善）  
4.TXT           设置文本指令（预留接口，待完善）

## 遥控器控制测试逻辑 ##
  使用SBUS的Switch_C与Switch_D联合控制
### Switch_D 负责控制串口屏使能状态 ###
  * 当遥控器的Switch_D拨杆拨到上方时，串口屏使能状态为失能
  * 当遥控器的Switch_D拨杆拨到下方时，串口屏使能状态为使能
### Switch_C 负责控制串口屏页面切换 ###
  * 当遥控器的Switch_C拨杆拨到上方时, 切换至预设页面0
  * 当遥控器的Switch_C拨杆拨到中间时, 切换至预设页面1
  * 当遥控器的Switch_C拨杆拨到下方时, 切换至预设页面2
### 遥控器操作建议 ###
  建议在串口屏失能状态下切换至目标页面对应的遥控器Switch_C拨杆，确认无误后将串口屏切换至使能状态，待画面成功切换后将串口屏使能状态切换回失能
